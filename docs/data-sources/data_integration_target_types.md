# List all target types

The catalog of targets a data flow can write to — read from the live Data Integration API, so a new
target appears here with no provider release.

## How it works

A target's shape depends on the combination of connection type and data-flow type, so each entry
carries `target_type` (the value for a data flow's `properties.target.name`), `connection_type` (which
connection it binds to), `logic_step_type`, and `data_flow_type_id`. Filter the list down to the
connection type you're targeting before writing the `target` block. This is the target-side
counterpart to [`boomi_data_integration_source_types`](./data_integration_source_types).

## Example Usage

```terraform
# Discover every target a data flow can write to — read from the live API,
# so new targets appear with no provider release.
data "boomi_data_integration_target_types" "all" {}

# The id to use as a data flow's properties.target.name.
output "target_type_ids" {
  value = [for t in data.boomi_data_integration_target_types.all.target_types : t.target_type]
}

# Which connection type each target binds to.
output "target_connection_types" {
  value = { for t in data.boomi_data_integration_target_types.all.target_types : t.target_type => t.connection_type }
}
```
