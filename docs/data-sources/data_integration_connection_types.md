# List all connection types

Browse every connection type the Data Integration API currently supports — Snowflake, MySQL, Jira,
S3, and everything else. Read directly from the live API, so a new connector shows up here with no
provider release.

## How it works

Use `boomi_data_integration_connection_types` to confirm a `type` value before you commit to it in a
[`boomi_data_integration_connection`](../resources/data_integration_connection) resource, or to build
your own tooling that browses the catalog. Once you know which type you want, read its exact
configurable fields with
[`boomi_data_integration_connection_type`](./data_integration_connection_type).

## Example Usage

```terraform
# Browse every connection type the live API currently supports — new
# connectors appear here automatically, with no provider release required.
data "boomi_data_integration_connection_types" "all" {}

output "connection_type_count" {
  value = length(data.boomi_data_integration_connection_types.all.connection_types)
}

# The slug to use as a boomi_data_integration_connection resource's `type`.
output "connection_type_ids" {
  value = [for c in data.boomi_data_integration_connection_types.all.connection_types : c.connection_type]
}
```
