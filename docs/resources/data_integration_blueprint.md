# boomi_data_integration_blueprint (Resource)

A Blueprint (the customer-facing term; the API/code term is "recipe"). A blueprint is a named pointer to a blueprint_file's content, used as a data_flow's source (source.name = "blueprint", source.additional_settings.recipe_id = this resource's id).

## Example Usage

```terraform
resource "boomi_data_integration_blueprint" "example" {
  name          = "Posts API"
  file_cross_id = "your-blueprint-file-id"  # from boomi_data_integration_blueprint_file
}
```

## Schema

### Required

- `file_cross_id` (String) The blueprint_file resource's id (cross_id) this blueprint points at. Updating this repoints the blueprint at new YAML content without changing the blueprint's own id.
- `name` (String) Blueprint display name.

### Optional

- `description` (String) Free-text description.
- `environment_id` (String) Environment this blueprint belongs to. Falls back to the provider-level environment_id. Changing it forces a new blueprint.

### Read-Only

- `id` (String) The cross_id assigned by the API. Reference this as a data_flow source's recipe_id.
