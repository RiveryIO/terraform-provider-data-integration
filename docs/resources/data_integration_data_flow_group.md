# boomi_data_integration_data_flow_group (Resource)

A data flow group (folder) — purely organizational, used to file data flows into folders in the console UI. Has nothing to do with permissions or access control.

## Example Usage

```terraform
resource "boomi_data_integration_data_flow_group" "etl" {
  environment_id = var.environment_id
  name           = "ETL Pipelines"
  color          = "#3399ff"
  icon           = "folder"
}

resource "boomi_data_integration_data_flow" "jira_issues" {
  environment_id = var.environment_id
  group_id       = boomi_data_integration_data_flow_group.etl.id
  name           = "jira-issues-to-snowflake"
  type           = "source_to_target"

  properties_json = jsonencode({
    properties_type = "source_to_target"
    source          = { name = "jira", connection_id = var.jira_connection_id, run_type = "regular" }
    target          = { name = "snowflake", connection_id = var.snowflake_connection_id, loading_method = "overwrite" }
  })
}
```

## Schema

### Required

- `name` (String) Display name of the group.

### Optional

- `color` (String) Display color of the group, as a hex or named color.
- `environment_id` (String) Environment this group belongs to. Falls back to the provider-level environment_id. Changing it forces a new group.
- `icon` (String) Icon identifier for the group.
- `is_default` (Boolean) Whether this is the environment's default group — rivers whose group is deleted are moved here. Only one group per environment can be default. Setting this true on one group implicitly unsets it on whichever group was previously default (which will show as drift there if that group is also managed by this provider). The API rejects explicitly setting this to false on the group that is currently default — make a different group default instead.

### Read-Only

- `id` (String) Cross ID of the group, assigned by the API.
