# PR Review Rules

## Focus areas
- Security: hardcoded secrets, tokens, API keys (credentials must come from env / `RIVERY_IAC_ENV_FILE`, never committed)
- A real Rivery river/data-flow `cross_id` or token committed to `rivers/*.json` or any file
- Error handling: bare `except:`, swallowed exceptions
- Missing timeouts on HTTP calls (`requests.*` without `timeout=`)
- Mutations that could hit a non-integration (production) environment
- Untested changes to `rivery_client.py` / `riverctl.py` (no corresponding test in `tests/`)

## Ignore
- Line length and import ordering (handled by ruff)
- Minor variable naming style

## Tone
Keep feedback concise. Flag only blocking issues inline; surface suggestions as a summary comment.
